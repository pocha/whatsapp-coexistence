STEP 3

How to Get Access to the WhatsApp Business API

Real (Advanced Access) use of the WhatsApp Business API — and Meta Tech Provider status — requires passing App Review. There's no separate self-serve toggle for Tech Provider status: submit the App Review request below and Meta's review covers both.

App Review requires two demo videos

Meta's reviewers need to see your app actually using the whatsapp_business_messaging and whatsapp_business_management permissions:

  • Video 1 — a message created and sent from your app, arriving in the WhatsApp client on the recipient's phone.
  • Video 2 — your app creating a message template, and that template showing up in WhatsApp Manager.

A pure onboarding-only app can't produce these on its own, which is why this project's Onboarding Dashboard ships small "test" buttons — send a message, create a template — solely to record these two videos. They're not part of the onboarding product itself; the dashboard's own page explains how to use them for recording, and the project README has the exact click-by-click steps.

Keep it simple

Reviewers are checking that the flow (login → action → result) is real and complete, not evaluating UI polish. Record both videos simply and unedited.

After approval

Once approved, you can turn the test buttons off — they hold WABA access tokens in memory to work, which is more exposure than the real onboarding flow needs. The onboarding flow itself discards the access token immediately after subscribing to the customer's WABA.
