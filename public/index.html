Getting Started

PRE-REQUISITE

WhatsApp Business API access, and a working app already using it. Don't have this yet? See the How-To Guides below.

STEP 1

Scan the QR code & activate Coexistence

Open the Dashboard and scan the QR code to link WhatsApp Business on the same number your API already uses.

STEP 2

Point us at your incoming-message endpoint

Give us your app's incoming-message API endpoint as the override target. Incoming messages then go directly from WhatsApp to your app — we're never in that path.

STEP 3

Send messages through the endpoint we provide

Update your app to send outgoing messages through our endpoint instead of directly. This is the only place we sit in the path — see why below.

Why we gatekeep outgoing messages: it's the one place we stay involved, purely so we can protect your number from getting banned — rate limiting and other anti-spam checks are (upcoming). Everything else — incoming messages, your access token — never touches us.

Features

🔒 No token storage

Your WABA access token lives in memory only, for as long as setup takes. Nothing is written to a database or disk, so there's nothing durable to leak.

⚡ Low latency

Incoming messages go directly from WhatsApp to your app — we're never in that path, so there's no extra hop slowing you down.

📖 Open source

Every line is on GitHub and self-hostable. Nothing is a black box — read the code, fork it, run your own copy.

🚦 Rate limiting for outgoing (upcoming)

Automatic rate limits on outgoing messages, so a misbehaving integration doesn't get your number banned.

📬 Per-recipient serialization (upcoming)

Messages to the same recipient get serialized, so retries or bugs on your end can't look like spam to WhatsApp.
