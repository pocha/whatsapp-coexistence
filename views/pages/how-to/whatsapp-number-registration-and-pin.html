WhatsApp Number Registration and the Two-Step PIN

Adding a number to a WhatsApp account is not the same as making it usable on the API. That last step is called registration, and it needs a six-digit PIN. Most people never do it themselves, because their provider does. It matters when something goes wrong, or when you move to another provider.

What registration is

  • A number can sit in your WhatsApp account and still not be usable on the Cloud API. Until it is registered, sends fail with "Account not registered" (error 133010).
  • Registration is one API call, made with a six-digit PIN. The PIN becomes the number's two-step verification PIN.
  • Registering doesn't need a new SMS or voice code. The number must already be verified.

When a number gets registered

  • A brand-new number added as API-only: the signup finishes, and the provider then calls register. This is the usual case.
  • A number added another way (through the API or in Business Manager rather than the signup): it joins the account, but nobody registers it until the provider makes the call.
  • A number that was deregistered and is being picked up again, for example when you move to another provider. The new provider registers it, and needs the existing PIN if two-step verification is on. If it's off, any six digits are accepted.
  • A recovery, when a number shows as not registered and the provider calls register again.
  • Never for coexistence numbers. They're already registered through the WhatsApp Business app, so the provider skips it.

The two-step verification PIN

  • Who sets it: whoever registers the number, usually your provider. Ask them for it, and keep it somewhere safe.
  • What needs it: Meta asks for the PIN when you change it, or delete the number in WhatsApp Manager. The next provider needs it when it registers the number.
  • Changing it: in WhatsApp Manager, Account tools → Phone numbers → the number → Two-step verification tab → Change PIN. This needs the current PIN. If you don't have it, your provider can set a new one through the API.
  • Turning it off: only in WhatsApp Manager, with the same flow ending in Turn off two-step verification. Meta emails a link to the address on your business portfolio. It can't be turned off through the API.

Errors you may see

  • 133010, "Account not registered": registration didn't happen or didn't finish. The provider has to call register. If it's a coexistence number, it shouldn't need to, so check it's still connected in the Business app.
  • 133016, too many attempts: Meta allows 10 registration requests per number in 72 hours. Stop, wait, then retry once with the right PIN. Every wrong PIN counts toward the limit.
  • A wrong PIN: the number already has a PIN and the one sent doesn't match. Get the right one from the previous provider, or turn two-step verification off in WhatsApp Manager and set a new PIN.
  • "This number is registered to an existing WhatsApp account": the signup tried to add the number as a brand-new one, and it's already on WhatsApp. See the move guide.

If you use Watobot

Watobot doesn't register numbers automatically. For a new number that isn't on the WhatsApp Business app, open the number's page in the dashboard and use the Register this number section, where you choose the PIN. Coexistence numbers don't need it.
