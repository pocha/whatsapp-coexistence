Already Have WhatsApp API? How to Migrate to Watobot

A phone number is connected to one WhatsApp Business Account (WABA) at a time, so if your number is already set up with another provider or your own Meta app, it has to be moved to us. It can't be connected in both places.

Moving a number that is already on the Cloud API

Meta's migration flow moves the number to a new WABA through Embedded Signup. Before you start, Meta requires:

  • A verified business portfolio. See our portfolio guide or Meta's business verification steps.
  • A WABA in good standing (not restricted or rejected).
  • A valid payment method on that WABA. How to add one.
  • An approved display name on the number, with no pending display name change. Display name guidelines.
  • Two-step verification disabled on the number. In WhatsApp Manager, go to Account tools → Phone numbers, select your number, open the Two-step verification tab and turn it off. It can't be turned off through the API. If your number has no such tab, there is nothing to disable. Meta's guide.

How the move works

There's no separate step to disconnect from your old provider. Meta's docs describe the move as part of the new provider's onboarding:

  1. Finish the prerequisites above.
  2. Start onboarding in our Dashboard and enter your phone number and display name in the popup.
  3. Meta creates the new WABA under us and moves the number. The old provider's connection ends automatically.
  4. Save the new access token and update your app. Tokens from your old provider stop working for this number.

One thing to know: your message templates carry over, but their quality ratings reset to UNKNOWN.

Does coexistence still work after migrating?

Meta's migration guide says migrated numbers work only with the Cloud API, which would mean the WhatsApp Business app stops working on that number. We haven't confirmed whether a number already on the Cloud API can be put into coexistence directly. If you want to keep using the Business app, the safest route is to check with Meta support first.
