Create your Watobot API key

We encrypt the access token Meta gives us for your number with a Watobot API key that only you hold. We'll show you the key once, so you can note it down.

Your Watobot API key

The key your apps use to call our API. We keep only a hash of it, and it encrypts the Meta access tokens we store for your numbers, so we can't read them without it. To replace it, enter the current key: nothing breaks, and every number keeps working with the new key. We sign you out afterwards, so you need the new key to sign in.

Use Watobot from an AI tool

An AI tool can check your callback URL, onboard a number, sync, register, send messages and manage templates. Meta's sign-up (Facebook login and the code in the WhatsApp Business app) is always done by you, in the browser. Paste your API key to get the setup for your tool (nothing is sent anywhere: it is put together in this page). We can't show the key again, so it has to come from where you saved it.

Claude.ai or ChatGPT (a connector)

Add a custom connector with this address and no authentication. The address holds your key, so treat it like the key.
