RAW API CALLS

Override incoming message URL / webhook

Incoming messages should reach your app (a chatbot, for example), so put your app's public HTTPS URL in the command. WhatsApp will then deliver messages straight to it. We check that it answers Meta's verification handshake first. To receive nothing, send {"noCallback": true} instead of a URL: no incoming messages or delivery receipts reach you then, and a coexistence number's one-time contacts and history sync is skipped for good. The Status card above shows where messages go now.

De-register this number

Takes the number off the WhatsApp API, so another provider can onboard it. It stops sending and receiving here. It does not delete the number or its message history, and needs no PIN. For a coexistence number this isn't possible: Meta refuses it, and the way off is in the WhatsApp Business app (Settings → Account → Business Platform → Disconnect). Meta allows 10 attempts per number in 72 hours. More
