WhatsApp Coexistence, made simple

Connect your customers' WhatsApp Business number via Meta's official Embedded Signup flow, then hand messaging off to their own server — this app doesn't stay in the message path. Open source, self-hosted, built for Meta Tech Providers.

Open Onboarding Dashboard View on GitHub

Features

🔒 Privacy First — no token storage

WABA access tokens issued during Embedded Signup live in memory only, for as long as onboarding takes. Nothing is written to a database or disk, so there's nothing durable to leak.

✅ Embedded Signup, done right

Runs Meta's own Embedded Signup popup so your customer connects their WhatsApp Business number in a few clicks — no manual WABA setup on your end.

🔀 Webhook Override

Once onboarding completes, message delivery can be routed straight to your customer's own webhook — this app gets out of the way instead of sitting in the middle of every message.

📖 Open Source

Every line is on GitHub and self-hostable. Nothing is a black box — read the code, fork it, run your own copy.
