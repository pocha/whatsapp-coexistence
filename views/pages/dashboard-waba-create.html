I forgot my API key

If you haven't already, create a Business Portfolio, connect your phone number on the WhatsApp Business app, and add it under Business Portfolio → WhatsApp accounts. Our guide walks through it.

Testing your callback URL

Right after onboarding, Meta sends your contacts and past chats (once, and it can't be repeated) to this URL, and every message and echo after that. Watobot doesn't keep any of it, so your endpoint must parse and save it. Meta gives 24 hours to request that sync, so we check your endpoint first.

Incoming messages, and delivery and read receipts for what you send, will reach no app of yours. Meta also sends the contacts and chat history sync only once, to a callback URL, so it is skipped and can't be done later. Replies still appear in the WhatsApp Business app. You can add a URL later from the number's page.

Don't have an endpoint yet? Use the test chatbot

The test chatbot is a small server that answers Meta's handshake and prints every event it receives, with any test code, so you can try this step without building anything. Follow its README to start it (it gives you a public HTTPS URL to paste above), and copy these into its .env, adding your Watobot API key as WATOBOT_API_KEY. It prints events instead of saving them, so it's for trying this flow: a real endpoint has to save the data.
