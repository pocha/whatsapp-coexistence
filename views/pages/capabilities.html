Capabilities: what Watobot supports for the WhatsApp API

What Watobot supports, so you can check it before you start: onboarding a number with coexistence or as API only, sending with limits that protect the number, message templates and moving them across, and leaving us again (de-registering and disconnecting). The same list is the one the project's README documents. Using it from an AI tool is a separate how-to.
